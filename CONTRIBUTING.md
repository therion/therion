## Pull requests

Please follow these rules when submitting pull requests (PR):

* Discuss proposed new features with the maintainers before implementing them.
* Keep each PR focused on one logical change. Do not combine unrelated
  changes or features in the same PR.
* Include all necessary documentation updates: summarize relevant changes in
  [CHANGES](https://github.com/therion/therion/blob/master/CHANGES) and update
  [thbook](https://github.com/therion/therion/tree/master/thbook) where needed.
  Follow the style of the existing documentation.
* Briefly explain what the PR changes and why. For code changes, test them
  and describe how you tested them in the PR description.
* Contributions may include AI-generated code, provided that:
  - you disclose any substantial use of AI tools in the PR description,
    briefly explaining how they were used and which parts of the contribution they helped produce;
  - you have reviewed and tested the code;
  - you understand it and can explain how it works;
  - you take responsibility for the contribution and are prepared to
    address review feedback and make necessary corrections.
